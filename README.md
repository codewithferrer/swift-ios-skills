# swift-ios-skills

Agent skills for iOS and Swift development, written as I need them for my own
apps and kept here so they can be reused across projects.

Each skill is a self-contained folder following the open
[Agent Skills](https://agentskills.io) format: a `SKILL.md` with instructions,
plus optional `references/`, `scripts/` and `examples/`. They work with Claude
Code and with any other agent that supports the format.

## Skills

| Skill | What it does |
|-------|--------------|
| [`app-store-release`](skills/app-store-release) | Automates App Store Connect release chores through Apple's API: status and build-failure diagnostics, pre-submission readiness check, localization audit (listing, purchases, subscriptions, Game Center), draft release notes from the git history, create a version and attach a build, push "What's New", store listing text and the names and descriptions of in-app purchases and subscriptions (with a diff before writing), upload screenshots, submit for review, release after approval, and read or reply to customer reviews. |
| [`ios-aso`](skills/ios-aso) | iOS-only App Store optimization: audits the name, subtitle, keyword field and localizations against Apple's rules, finds wasted or repeated keywords across storefronts, packs a ranked keyword list into the 100-character field, researches a competitive segment from Apple's public data (who ranks above their weight, what their names and users say), and guides conversion work and measurement. Every claim is labelled as Apple-stated, observed or industry-reported. |
| [`ios-release-train`](skills/ios-release-train) | The repository side of shipping an iOS version: reads the app's real version and build (not the first match in the project file), checks the repo is ready, bumps the build only on the targets that ship, closes the changelog, and creates and pushes the release tag that starts CI. Previews by default; nothing is pushed without an explicit flag. |
| [`ios-xcstrings`](skills/ios-xcstrings) | Checks and translates Xcode String Catalogs: coverage per language, format specifiers that would crash or garble text, plural forms each language needs, stale keys that are really in use, and a way to write translations that changes only the keys you translate and keeps Xcode's formatting. Previews by default. |
| [`ios-analytics`](skills/ios-analytics) | Understands and audits an iOS app's analytics: inventories the events its code records, finds the screens, controls, errors, permission prompts and purchases that leave no trace, checks names, parameter cardinality, privacy and Firebase/GA4 limits, compares the code with an event plan and suggests where each missing event goes. Read-only. |

## Install

### Any agent, with the skills CLI

```sh
npx skills add codewithferrer/swift-ios-skills                      # pick interactively
npx skills add codewithferrer/swift-ios-skills --skill app-store-release
npx skills add codewithferrer/swift-ios-skills --all
```

### Claude Code, as a plugin marketplace

Add the marketplace once:

```sh
/plugin marketplace add codewithferrer/swift-ios-skills
```

Then install one skill, or all of them:

```sh
/plugin install app-store-release@codewithferrer-skills
/plugin install all-skills@codewithferrer-skills
```

### By hand

Copy or symlink the skill folder you want into a skills directory:

```sh
git clone https://github.com/codewithferrer/swift-ios-skills.git
ln -s "$PWD/swift-ios-skills/skills/app-store-release" ~/.claude/skills/app-store-release
```

Use `<project>/.claude/skills/` instead of `~/.claude/skills/` to scope a skill
to one project. Symlinking means `git pull` updates the skill in place.

### Claude desktop and web

Zip the skill folder and upload it under **Customize -> Skills**.

## Layout

```
skills/
  <skill-name>/
    SKILL.md          required: frontmatter (name, description) and instructions
    references/       optional: detail loaded only when needed
    scripts/          optional: code the skill runs
    examples/         optional: templates
.claude-plugin/
  marketplace.json    generated by scripts/skills_repo.py sync
scripts/
  skills_repo.py      validate the repo and regenerate the marketplace
```

Skills here never depend on each other, so you can install any one alone.

## Adding a skill

See [AGENTS.md](AGENTS.md). In short: create `skills/<name>/SKILL.md`, run
`python3 scripts/skills_repo.py sync`, add a row to the table above, and run
`python3 scripts/skills_repo.py validate`. CI runs the same check.
